# Report Policy

`verifiable-report-policy-v1` is immutable and checksum-addressed. It allowlists
four report types, `zh-CN` and `en-US`, the closed Section registry, exact
excerpt/block bounds, two Reflection rounds and one Revision round.

The Policy requires Claim, Evidence and valid document-Citation bindings; keeps
unsupported, conflicting, data-quality and limitation states visible; forbids
unknown publication time and Synthetic evidence in real-company research; and
sets both model Narrative and model Reflection permissions to false.

A `BLOCKED` Package may produce only the data-quality equivalent. A `PARTIAL`
Package must remain visibly partial and cannot pass as a complete report. Policy
versions are seeded explicitly and never selected from arbitrary request input.
